# Капсулярная контрактура — рилс-анимация

Рилс для рубрики «Разбор»: 1080 × 1920, 59 с, 30 к/с. Оформлен по дизайн-системе «Макс Ермизин»: палитра «День», Onest / Playfair Display Italic / IBM Plex Mono, фирменная разметка маркером.

Три шага:

1. **Формирование** (00:04). Белки плазмы → макрофаги → гигантские клетки инородных тел → фибробласты и коллаген. Капсула тонкая и мягкая.
2. **Сокращение** (00:22). Биоплёнка, миофибробласты (α-SMA), коллаген уплотняется и выпрямляется, капсула толстеет.
3. **Деформация** (00:40). Объём геля постоянен, капсула меньше, поэтому имплант скругляется и уходит вверх. Затем шкала Бейкера I–IV.

Финал закольцован: последний кадр совпадает с первым, пустая бумага перед пунктиром-«миндалём».

## Файлы

| Путь | Что |
| --- | --- |
| `index.html`, `js/` | исходники: плеер и анимация на Canvas 2D; каждый кадр — чистая функция времени |
| `dist/capsular-contracture.html` | та же страница одним файлом (`python3 tools/build.py`) |
| `export/capsular-contracture-1080x1920.mp4` | готовый рилс: H.264 High, yuv420p, беззвучная AAC-дорожка |
| `export/capsular-contracture-1080x1920-cover.png` | обложка рилса; текст в зоне y 860–1500, сетка профиля его не срежет |
| `tools/render.cjs` | экспорт в MP4 и обложки через Playwright + ffmpeg |

## Экспорт

```sh
NODE_PATH=$(npm root -g) FFMPEG=/путь/к/ffmpeg node tools/render.cjs
```

Нужны Playwright с Chromium и ffmpeg с libx264. Если Google Fonts недоступны напрямую, передайте `FONTS_DIR`: это папка с `gf.css` и файлами шрифтов.

## Правка текста

Субтитры лежат в `js/hud.js`, массив `CARDS`: `[начало, конец, текст]`. Главы там же в `CHAPTERS`, «часы» в `CLOCK`. Все остальные тайминги — в `js/scenes.js`.

Что упрощено: размеры белков, бактерий и клеток условные, сроки ориентировочные.
