# Почему редеют волосы и что может PRP — рилс-анимация для пациентов

Рилс для рубрики «Разбор»: 1080 × 1920, 64 с, 30 к/с, закольцован. Язык — для пациента: без
названий ферментов, сигнальных молекул и статистики; термины заменены на то, что они значат.
Оформлен по дизайн-системе «Макс Ермизин»: палитра «День», Onest / Playfair Display Italic /
IBM Plex Mono, фирменная разметка маркером, субтитры на чернильной плашке, линза-«микроскоп»,
зерно бумаги. Собран на Remotion: каждый кадр — чистая функция времени.

Три главы:

1. **Причина** (00:04). Волос растёт из корня 2–6 лет, отдыхает, выпадает, растёт новый. В линзе:
   мужской гормон в коже превращается в DHT, DHT цепляется к клеткам корня и даёт команду
   «расти меньше». С каждым циклом волос тоньше и короче — до пушка.
2. **PRP** (00:24). Плазма из собственной крови: центрифуга, слой с тромбоцитами. В линзе:
   тромбоциты выделяют факторы роста (показаны как «рост клеток», «новые сосуды», «защита»,
   «питание»), клетки корня просыпаются, растут сосуды. Инъекция тонкой иглой, три сеанса,
   потом поддержка.
3. **Чего ждать** (00:44). Шкала ожиданий: «заметно гуще», но не «как в 18»; примерно
   +15–30 волос на см² с разбросом. Оговорки: помогает не всем, лучше на ранних стадиях,
   эффект через 3–6 месяцев, нужна поддержка. Карточки: таблетки и миноксидил — основа,
   PRP — дополнение.

Финал: «Причина — гормон. Основа — лекарства. PRP — дополнение.» Последний кадр совпадает
с первым: пустая бумага и пунктирный контур корня волоса.

## Файлы

| Путь | Что |
| --- | --- |
| `src/reel/` | исходники: палитра, изинги, маркерная разметка, HUD, сцены, режиссура (`Reel.tsx`), обложка |

## Запуск

```sh
npm install
npm start            # Remotion Studio
npm run render       # export/aga-prp-reel-1080x1920.mp4
npm run cover        # export/aga-prp-reel-1080x1920-cover.png
npm run stills -- out/stills "2,8,15,30,45"
```

В контейнере без загрузки Chrome Headless Shell укажите готовый браузер:
`REMOTION_BROWSER_EXECUTABLE=/путь/к/headless_shell npm run render`.

## Правка текста

Субтитры — `src/reel/script.ts`, массив `CARDS`: `[начало, конец, текст]`. Главы там же в `CHAPTERS`,
«часы» в `CLOCK`. Подписи на иллюстрациях — в `src/reel/Reel.tsx` и `src/reel/scenes/Micro.tsx`.
Тайминги линз и сцен — константы в `Reel.tsx` и `scalpState()` в `src/reel/scenes/Scalp.tsx`.

## Что упрощено и как это соотносится с медициной

| В ролике | Что имеется в виду |
| --- | --- |
| «мужской гормон превращается в DHT», «особый фермент» | тестостерон → дигидротестостерон под действием 5α-редуктазы II типа |
| «DHT цепляется к клеткам корня» | связывание с андрогеновым рецептором в клетках дермального сосочка |
| «команда: расти меньше», «стоп-сигнал» | паракринные сигналы TGF-β, DKK-1, IL-6 → укорочение анагена |
| «рост клеток», «новые сосуды», «защита», «питание» | PDGF, IGF-1 (пролиферация), VEGF (ангиогенез), Bcl-2/анти-апоптоз, FGF/EGF |
| «сигнал: расти» | активация Wnt/β-catenin (данные преимущественно in vitro и на животных) |
| «+15–30 волос на см²», «разброс» | пуловые оценки мета-анализов 2017–2022 (Giordano, Gupta, Mao, Evans) с широкими ДИ |
| «таблетки» | финастерид 1 мг (у женщин — по назначению врача) |
| «основа / дополнение» | уровень доказательности A у финастерида и миноксидила; PRP — адъювант с низкой–умеренной достоверностью |

Размеры клеток, молекул и слоёв условные; масштаб «1 мм» ориентировочный; схема «3 сеанса,
потом раз в полгода» — наиболее частая в исследованиях, единого стандарта нет.
