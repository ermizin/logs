# Андрогенетическая алопеция и PRP — рилс-анимация

Рилс для рубрики «Разбор»: 1080 × 1920, 64 с, 30 к/с, закольцован. Оформлен по дизайн-системе
«Макс Ермизин»: палитра «День», Onest / Playfair Display Italic / IBM Plex Mono, фирменная разметка
маркером, субтитры на чернильной плашке, линза-«микроскоп», зерно бумаги. Собран на Remotion:
каждый кадр — чистая функция времени.

Три главы:

1. **Гормон** (00:04). Цикл волоса, затем линза в луковицу: тестостерон → 5α-редуктаза II → DHT →
   рецепторы клеток дермального сосочка → TGF-β, DKK-1 → фаза роста короче. Фолликул мельчает
   с каждым циклом: терминальный волос становится пушковым.
2. **PRP** (00:24). Кровь → центрифуга → плазма, тромбоцитарный слой, эритроциты. Линза: тромбоцит
   активируется, факторы роста (PDGF, VEGF, IGF-1, TGF-β, FGF-2) будят клетки сосочка, Wnt/β-catenin,
   растут сосуды. Инъекция в дерму, три сеанса, частичное восстановление.
3. **Данные** (00:44). Мета-анализы: ≈ +15…+30 волос/см² с широким ДИ; малые выборки, высокая
   гетерогенность, разные протоколы. Карточки: финастерид и миноксидил — основа, PRP — дополнение.

Финал: «DHT — причина. Финастерид — основа. PRP — дополнение.» Последний кадр совпадает с первым:
пустая бумага и пунктирный контур фолликула.

## Запуск

```sh
npm install
npm start            # Remotion Studio
npm run render       # export/aga-prp-reel-1080x1920.mp4
npm run cover        # export/aga-prp-reel-1080x1920-cover.png
npm run stills -- out/stills "2,8,15,30,45"
```

В контейнере без загрузки Chrome Headless Shell укажите готовый браузер:
`REMOTION_BROWSER_EXECUTABLE=/путь/к/headless_shell npm run render`.

## Что здесь факт, а что версия

- **Факт.** АГА — андроген-зависимая миниатюризация фолликулов: DHT образуется из тестостерона
  под действием 5α-редуктазы II, связывается с AR в клетках дермального сосочка; паракринные сигналы
  (TGF-β, DKK-1, IL-6) укорачивают анаген. Финастерид (1 мг) и миноксидил — терапия с уровнем
  доказательности A.
- **Факт.** PRP — аутологичный концентрат тромбоцитов (×3–5); α-гранулы содержат PDGF, VEGF, IGF-1,
  TGF-β, FGF-2. Мета-анализы 2017–2022 показывают статистически значимый, но умеренный прирост
  плотности волос с широкими доверительными интервалами и высокой гетерогенностью.
- **Версия.** Механизм действия PRP на фолликул (пролиферация клеток сосочка, Wnt/β-catenin,
  ангиогенез, удлинение анагена) показан преимущественно in vitro и на животных; клинические
  подтверждения — малые серии с биопсиями (↑ Ki-67, ↑ сосудов).
- **Упрощения.** Размеры клеток, молекул и слоёв условные; масштаб «1 мм» ориентировочный;
  сроки миниатюризации (циклы) и восстановления после сеансов схематичны; протокол «3 сеанса раз
  в месяц, потом поддержка» — наиболее частая схема в исследованиях, единого стандарта нет.
