# AGA · PRP — Remotion motion graphic

Анимационный ролик (1920×1080, 30 fps, ≈ 3 мин) про андрогенетическую алопецию (АГА)
и PRP-терапию: патогенез (каскад DHT → миниатюризация), классификация, базовая терапия,
приготовление и механизм PRP, протокол, доказательная база, безопасность.

## Структура

```
src/
  AgaPrpVideo.tsx      сборка сцен через TransitionSeries (fade / slide)
  timeline.ts          длительности сцен, fps, разрешение
  theme.ts             палитра, шрифт, бейджи уровней доказательности
  fonts.ts             загрузка Inter (latin + cyrillic) через staticFile()
  components/          SceneFrame, Reveal, Bullets, Badge, Card, Arrow
  scenes/              12 сцен
scripts/copy-fonts.mjs копирует woff2 из @fontsource/inter в public/fonts (postinstall)
```

## Запуск

```bash
npm install
npm start                # Remotion Studio
npm run render           # out/aga-prp.mp4 (H.264, 1080p)
npm run render:preview   # быстрый превью-рендер в половинном масштабе
```

В контейнере без доступа к загрузке Chrome Headless Shell укажите готовый браузер:

```bash
REMOTION_BROWSER_EXECUTABLE=/path/to/chromium npm run render
```
